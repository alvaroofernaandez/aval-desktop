# Architecture decision records

One decision per file, `NNNN-kebab-case.md`, numbered from 0001. Sections:
Context, Decision, Rejected alternatives, Consequences, and an optional
Amendments section with dated entries. An accepted ADR is never rewritten.

The first record chooses the GUI toolchain. Decisions that bind this app and
core together live in aval: see its
[ADR 0008](https://github.com/alvaroofernaandez/aval/blob/main/docs/adr/0008-process-boundary-core-memory-desktop.md).
